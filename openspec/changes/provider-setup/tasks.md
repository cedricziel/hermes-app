# Tasks

Five PRs, each about 500 changed lines or fewer with tests, merged in order. No API route is added or changed, so `openapi/hermes-agent.openapi.json` and `packages/hermes_api` stay as they are. Every behaviour task starts with a failing test against `FakeHermesServer` (the real generated client), never a mock of the client.

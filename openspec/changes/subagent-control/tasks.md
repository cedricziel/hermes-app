# Tasks

PRs 1 to 3 add no UI; PR 4 adds the widgets in the catalog only (agents and program cards); PR 5 puts the agent widgets on screen; PR 6 does the same for background programs and can ship later on its own. Each PR ends with its own verify task. Device checks are listed at the end.
